O que é Desenvolvimento Web?

O processo de planejar, construir e manter tudo o que você acessa através de um navegador.

Desenvolvimento Web é o conjunto de práticas usadas para criar sites e aplicações que funcionam pela internet. Isso envolve estruturar conteúdo, definir a aparência visual e programar comportamentos e regras de funcionamento.

Um site costuma ser mais estático, voltado à exibição de informações — como um blog institucional. Já uma aplicação web é interativa e permite que o usuário execute ações, como enviar formulários, fazer login ou comprar um produto.

Tecnologias fundamentais

Três camadas que, juntas, formam qualquer página que você visita.

Estrutura

HTML

Responsável pela estrutura e organização do conteúdo da página.

Estilo

CSS

Responsável pela aparência, layout, cores, fontes e responsividade.

Interatividade

JavaScript

Responsável por comportamentos, lógica e interações da página.

HTML

HTML (HyperText Markup Language) é a linguagem de marcação usada para estruturar o conteúdo de uma página. Ela define elementos como títulos, parágrafos, imagens, links e formulários.

Toda página web começa com HTML: é o "esqueleto" sobre o qual CSS e JavaScript atuam.

CSS

CSS (Cascading Style Sheets) controla a apresentação visual do HTML: cores, espaçamentos, tipografia, layout e comportamento responsivo.

É o CSS que transforma uma página sem estilo em uma interface agradável e coerente com uma identidade visual.

JavaScript

JavaScript é a linguagem que adiciona lógica e interatividade às páginas: validações, animações, requisições a servidores e manipulação do DOM em tempo real.

É o que permite que uma página reaja a cliques, digitação e outros eventos do usuário.

01 · Estrutura

HTML

HTML organiza o conteúdo através de elementos, formados por tags de abertura e fechamento, que podem receber atributos.

  • Elementos e tags (<p>, <h1>, <img>)
  • Atributos (class, id, src)
  • Estrutura de documento (head, body)
  • HTML semântico (header, main, section)

Como uma página web funciona?

Do clique no link até a página aparecer na sua tela — em sete etapas.

01

Usuário acessa uma URL

Digita um endereço ou clica em um link.

02

Navegador realiza uma requisição

Envia uma solicitação HTTP para o servidor correspondente.

03

Servidor recebe a requisição

Identifica o que está sendo pedido.

04

Servidor processa os dados

Pode consultar bancos de dados e executar lógica de negócio.

05

Resposta é enviada

O servidor devolve HTML, CSS, JS e dados ao navegador.

06

Navegador interpreta o conteúdo

Monta a página a partir de HTML, CSS e JavaScript.

07

Página é exibida

O resultado final aparece na tela do usuário.
